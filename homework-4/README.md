This homework implements a small Python REST API (`Bill Splitter API`) and a
4-agent pipeline for research verification, bug fixing, security verification,

## Single-command pipeline execution

The pipeline is a **real agent orchestrator**. One command runs all four agents
in order via the Cursor CLI (`cursor-agent`); each agent uses the model declared
in its `*.agent.md` frontmatter, reads its own skills, and writes its own
artifact.

```powershell
./run-pipeline.ps1
```

What the orchestrator (`run_pipeline.py`) does:
1. Resets `src/` and `tests/` from `seed/` to the original buggy state.
2. Runs Research Verifier (`gpt-5.5-medium`) -> `verified-research.md`.
3. Runs Bug Fixer (`composer-2.5-fast`) -> edits `src/` + `fix-summary.md`.
4. Runs Security Verifier (`gpt-5.5-medium`) -> `security-report.md`.
5. Runs Unit Test Generator (`composer-2.5-fast`) -> `tests/` + `test-report.md`.

Each step is retried on transient failures, and raw agent output is saved to
`context/bugs/001/logs/` as evidence.
